# Changelog

> Following [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
> and [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-10-09

First release, extracted from the signify-rs project with its history.

### Added

- Protocol versions and version strings, the deterministic self-addressing-data codec, and the
  KERI message serializer and parser.
- Self-addressing identifiers and identifier prefixes, derived and verified.
- Exact numeric and weighted signing thresholds.
- Key event builders (`icp`, `rot`, `ixn` and their delegated forms), exchange and reply messages,
  timestamps, witness fault tolerance and configuration traits.
- CESR attachments composed around a message, and the TEL registry inception event.
- Cross-language fixtures generated by [signify-ts] and [keripy], with both references pinned by
  commit through npm and uv.

[signify-ts]: https://github.com/WebOfTrust/signify-ts
[keripy]: https://github.com/WebOfTrust/keripy
