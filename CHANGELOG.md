# Changelog

> Following [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
> and [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2026-10-26

### Added

- `stream`: parses incoming KERI v1 message streams back into events and typed attachment
  groups, the inverse of `attachment`, verified against keripy's parser.
- `event::receipt`: builds and reads the `rct` receipt message, verified against keripy's
  builder and field table.
- `event::query`: builds and reads the `qry` query message with typed `logs`, `ksn` and `mbx`
  arguments, verified against keripy's builder, askers and field table; `EventKind::Query`.
- `event::key_state`: builds, reads and compares the key state record a `ksn` query is answered
  with, verified against keripy's `state`, `KeyStateRecord` and `diffState`.
- `event::reply::route`: typed `/end/role`, `/loc/scheme`, `/ksn` and `/watcher` reply routes,
  and `ReplyMessage::from_serialized`, verified by running replies through keripy's router and
  handlers.
- `event::reply::acceptance`: best-available-data acceptance of a reply over the one already
  accepted for its route, verified against keripy's `Revery.acceptReply` over real identifiers.
- `attachment`: `SignedMessageBuilder` writes a delegated event's source couple (`-G`), validators'
  receipt quadruples (`-D`) and a first-seen couple (`-E`), in the order keripy's `cloneEvtMsg`
  writes a log replay; `ReceiptQuadruple::new` and `FirstSeenReplayCouple::new` build them.

### Changed

- `EventKind` gains the `Query` variant, so exhaustive matches on it need a new arm, and
  `EventKind::ALL` now holds fifteen kinds.
- `EventError` messages for wrapped failures now describe parsing as well as derivation and
  encoding, and every rejected value is quoted.

## [0.1.0] - 2026-10-10

First release, extracted from the signify-rs project with its history.

### Added

- Protocol versions and version strings, the deterministic self-addressing-data codec, and the
  KERI message serializer and parser.
- Self-addressing identifiers and identifier prefixes, derived and verified.
- Exact numeric and weighted signing thresholds.
- Key event builders (`icp`, `rot`, `ixn` and their delegated forms), exchange and reply messages,
  timestamps, witness fault tolerance and configuration traits.
- CESR attachments composed around a message, and the TEL registry inception event.
- Cross-language fixtures generated by [signify-ts] and [keripy], with both references pinned by
  commit through npm and uv.

[signify-ts]: https://github.com/WebOfTrust/signify-ts
[keripy]: https://github.com/WebOfTrust/keripy
